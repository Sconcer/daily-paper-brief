# Name decision: Daily Paper Brief

Decision date: 2026-09-03.

## Selected names

- Project and repository: **Daily Paper Brief** / `daily-paper-brief`
- Generated document: **Daily arXiv Report / 每日 arXiv 论文分析报告**

The project name is deliberately source-neutral. The generated document names
arXiv only to identify the source being reported on.

## Why this name

`Daily Paper Brief` is descriptive, easy to search, and does not imply that the
software performs formal peer review or proves paper correctness. The report
itself is detailed; “Brief” describes the daily research-intelligence artifact,
not a promise that every paper receives only a short abstract.

The initially considered `Daily Paper Report` name was rejected because an
active, highly similar public repository already uses that exact name. Names
that brand the project itself with “arXiv” were also rejected because arXiv's
API guidance asks independent projects not to use arXiv names as project
branding or imply endorsement.

## Brand boundary

- Use `Daily Paper Brief` in repository metadata, package identifiers, user
  agents, cron names, and project documentation.
- Use `Daily arXiv Report` only as the title of a report whose source is arXiv.
- Keep the independent-project disclaimer and requested data acknowledgement.
- Do not use arXiv logos, visual identity, or wording that implies sponsorship.

Name checks reduce obvious collision risk; they are not legal trademark
clearance.
